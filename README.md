This repo now includes a Vercel-ready skeleton and placeholder assets (logo, favicon, and Open Graph image). Replace the placeholder SVGs in public/ with your high-resolution PNGs (the original icon you uploaded) to use the final artwork.

How to replace with the real icon
1. Save your icon files locally (favicon.ico, og-image.png, logo.png).
2. Upload them to public/ or overwrite the SVGs:
   - public/logo.svg -> public/logo.png (or both)
   - public/og-image.svg -> public/og-image.png
   - public/favicon.svg -> public/favicon.ico (or keep svg as favicon)

Then commit and push to the branch and Vercel will pick them up on deploy.
